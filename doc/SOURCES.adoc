== Confidence labels

Use:

* `documented` — primary public documentation;
* `observed` — reproducible hardware/guest observation;
* `inferred` — strongest model consistent with evidence;
* `hypothesis` — not yet verified.

Code comments should not present `hypothesis` as `documented`.
