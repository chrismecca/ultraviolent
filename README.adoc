= Ultraviolent
:toc:
:toclevels: 2
:source-highlighter: highlight.js

Ultraviolent is a clean-room virtual hardware platform for SGI-class systems.

Its purpose is to run original, unmodified guest firmware and operating systems against
hardware-compatible machine personalities while allowing the implementation beneath
those interfaces to use modern CPUs, storage, networking, graphics APIs, or physical
hardware.

The first machine personality is a minimal SGI Origin 2000 / IP27 system. The first
public release, *RC-IP27*, is earned when unmodified IRIX can be installed, booted,
networked, and logged into over telnet from another host.

Ultraviolent is not an IRIX port. It is not an application compatibility layer. It is not
a cycle-accurate R10000 simulator. It is a virtual machine whose contract is the
guest-visible hardware.

== Foundation

----
The guest changes as little as possible.
The future underneath it may change completely.

Machines own topology.
Devices own behavior.
The core owns execution mechanics.
Backends own host integration.
----

A physical SGI device may be represented by software today, a Vulkan backend tomorrow,
or an FPGA later. IRIX must continue to see the same hardware contract.

== Initial scope

RC-IP27 targets one deliberately small IP27 machine:

* one IP27 node
* one R10000-class CPU
* one Hub
* enough Xtalk/XIO/XBOW topology to represent the real machine correctly
* one IO6/BaseIO path
* Bridge/PCI
* IOC3 serial and Ethernet
* ISP1020/SCSI
* one system disk and installation CD-ROM
* persistent NVRAM/flash where required
* original PROMs and unmodified IRIX supplied locally by the user

The initial execution engine is an interpreter.

== Build host

Linux/x86-64 is the first-class host. Debian GNU/Linux 13 is the reference development environment.
Other hosts may work later, but they must not distort the core design.

See `doc/DEVELOPMENT.adoc`.

== Private assets

No SGI firmware, IRIX installation media, installed disk image, NVRAM dump, or other
proprietary binary belongs in the public repository.

Ultraviolent accepts user-supplied paths to local assets. The recommended local layout is
documented in `assets/README.adoc`.

== Name

"Ultraviolent" is a deliberate play on the SGI color/optics lineage: IRIS, Indigo,
ultraviolet. The name is not intended to imply compatibility with or endorsement by SGI.
