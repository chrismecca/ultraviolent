= Private Assets

This directory is where your own SGI firmware and IRIX media go. Git ignores everything in
it except this README; Ultraviolent ships no SGI or IRIX binaries and never downloads them
(`doc/CLEANROOM.adoc`).

== Layout

The scripts look here by default (`doc/USING.adoc` "What you need"):

----
assets/
├── firmware/
│   ├── ip27prom.img      the IP27 node board's PROM image
│   └── io6prom.img       the BaseIO board's PROM image
└── media/
    ├── IRIX-6.5-Foundation1.iso
    ├── IRIX-6.5-Foundation2.iso
    ├── IRIX 6.5.30 Installation Tools and Overlays (1 of 3).iso
    ├── IRIX 6.5.30 Overlays (2 of 3).iso
    └── IRIX 6.5.30 Overlays (3 of 3).iso
----

Elsewhere works too: `ULTRAVIOLENT_IP27_PROM` names the IP27 PROM (the BaseIO PROM is
looked for beside it), `ULTRAVIOLENT_IRIX_MEDIA` or `--media` the disc directory.

Installed machines (disk, NVRAM, and flash files) belong in the ignored `local/` directory,
for example `local/vm/`, not here.

== Integrity

`doc/RELEASE-NOTES-RC-IP27.adoc` lists the SHA-256 of the files the installation was
demonstrated with:

[source,shell]
----
sha256sum assets/firmware/* assets/media/*
----

Keep private asset paths and hashes of your own hardware out of portable test expectations.
